# Triage Labels

Use this one-to-one vocabulary in local ticket `Labels:` metadata and preserve
it if tickets are later migrated to an external tracker.

- `needs-triage`: classification or verification has not finished.
- `needs-info`: progress requires information from a stakeholder.
- `ready-for-agent`: the work is specified and can be implemented autonomously.
- `ready-for-human`: the next action requires human authority or external access.
- `wontfix`: the request was deliberately rejected with the reason recorded.
