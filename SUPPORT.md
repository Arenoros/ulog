# Support

Ulog is in pre-release development. Use the repository issue tracker for
reproducible build failures, portability problems, and proposed features. Include
the operating system, compiler and version, CMake version, Conan profile, static
or shared linkage, and a minimal reproducer.

Security-sensitive reports must follow `SECURITY.md` rather than a public issue.
General questions should reference the applicable ADR or Performance Contract
section so architectural assumptions are visible.
